# Шифровальщик данных
Шифрование и расшифрование файлов и текста. AES-256-CBC, ключ через PBKDF2 (100 000 итераций, SHA-256).

Реализовано шифрование и расшифрование файлов и текста по алгоритму AES-256-CBC с генерацией ключа через PBKDF2 (100 000 итераций, SHA-256) и выводом текстового результата в формате Base64.

## Установка и запуск
### Вариант 1: Через терминал (CLI)
npm install
npm start

### Вариант 2: С помощью графического установщика
Запустите файл `Encryptor Setup 1.0.0` и следуйте инструкциям на экране.

## Как пользоваться
1. Для шифрования файла: вкладка «Файлы», введите пароль, укажите исходный файл и путь сохранения, нажмите «Зашифровать».
2. Для расшифрования файла: вкладка «Файлы», введите пароль, укажите зашифрованный файл и новый путь, нажмите «Расшифровать».
3. Для шифрования текста: вкладка «Текст», введите пароль и текст, нажмите «Зашифровать». Результат — Base64.
4. Для расшифрования текста: вкладка «Текст», введите пароль и Base64-строку, нажмите «Расшифровать».
