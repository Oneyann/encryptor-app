# Шифровальщик данных

Шифрование и расшифрование файлов и текста.
AES-256-CBC, ключ через PBKDF2 (100 000 итераций, SHA-256).

## Установка и запуск
### Вариант 1: Через терминал (CLI)
```
npm install
npm start
```
### Вариант 2: С помощью графического установщика
Запустите файл Encryptor Setup 1.0.0 и следуйте инструкциям на экране.

## Шифрование файла

Вкладка «Файлы». Введите пароль, укажите исходный файл и путь сохранения, нажмите «Зашифровать».

## Расшифрование файла

Вкладка «Файлы». Введите пароль, укажите зашифрованный файл и новый путь, нажмите «Расшифровать».

## Шифрование текста

Вкладка «Текст». Введите пароль и текст, нажмите «Зашифровать». Результат — Base64.

## Расшифрование текста

Вкладка «Текст». Введите пароль и Base64-строку, нажмите «Расшифровать».
